# HomeAssistant -> SecuritySpy Integration

This software allows HomeAssistant to access SecuritySpy events.
That means you can trigger other HASS actions based on events SecuritySpy is reporting.
This integration watches the SecuritySpy event stream to allow real-time decisions.

It also allows provides custom actions so you can control SecuritySpy.
That means you can dynamically arm or disarm camera events, and update schedules & overrides.
